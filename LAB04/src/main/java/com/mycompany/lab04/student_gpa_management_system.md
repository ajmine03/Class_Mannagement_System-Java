Problem: Student GPA Management System

Story:
A teacher wants to manage the academic records of three students in a class. Each student has a name and a GPA.
The teacher wants to create a simple Java program to store student information,
display their details, and calculate the average GPA of the class.

Student Information:
Your Task:
- Write a Java program using OOP concepts that:
- Creates a StudentRecord class with private variables for name and GPA.
- Uses a constructor to initialize each student's information.
- Uses a static variable to count the total number of students created.
- Stores three student objects in an array.
- Displays each student's name and GPA.
- Calculates and displays the average GPA and total number of registered students.

Expected Output:
Student: Alice | GPA: 3.85
Student: Bob | GPA: 3.6
Student: Charlie | GPA: 3.9
Total Registered: 3
Average GPA: 3.783333333333333
